# Miguel Faraj — signature + profile page

Put this `Signatures/` folder inside the **Home** repo (SociallyMiddleEast/Home) and push.

- Profile page: https://sociallymiddleeast.github.io/Home/Signatures/
- Signature to copy: https://sociallymiddleeast.github.io/Home/Signatures/signature.html

## Install the signature
1. Push first — the signature loads its images from the live site.
2. Open `signature.html` on the live site → **Copy signature**.
3. Gmail: Settings → See all settings → Signature → paste.
   Outlook: Settings → Mail → Compose and reply → paste.

## Files
- `index.html` — profile page (opened by clicking the photo / name in the signature)
- `signature.html` — the email signature + copy button
- `miguel-faraj.vcf` — "Save my contact" card
- `img/` — logo, icons, `portrait.jpg` (profile hero), `sig-photo.png` (sliced signature photo)

Placeholders to replace: `img/portrait.jpg`, `img/sig-photo.png`, `img/logo.png`.
