SociallyADMIN · FIRST-TIME SETUP

Set up admin access

This is done once. The admin saves your changes into your GitHub repository, so it needs a GitHub access key. The key is locked with the username and password you choose here and can't be used without them.

1. Create a GitHub access key
  1. Open GitHub → Fine-grained tokens → Generate new token (signed in as the account that owns the website repository).
  2. Name: Socially Admin. Expiration: up to 1 year. Resource owner: the owner of the website repo.
  3. Repository access: Only select repositories → your website repository.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate, copy the key and paste it below.
